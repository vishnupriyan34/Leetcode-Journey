---

# 💡 Problem-Solving Approach

For every problem, I try to follow these steps:

### 1️⃣ Understand the Problem

Identify the inputs, outputs, constraints, and expected behavior.

### 2️⃣ Think of a Brute-Force Solution

Start with a simple approach to understand the problem.

### 3️⃣ Optimize

Look for better:

* Time complexity
* Space complexity
* Data structures
* Algorithms

### 4️⃣ Implement

Write the solution in Python.

### 5️⃣ Test

Test the solution against:

* Normal cases
* Edge cases
* Large inputs
